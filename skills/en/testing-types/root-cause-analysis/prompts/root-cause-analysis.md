# Root Cause Analysis Prompt
## Input audit and analysis
Audit event, logs, change, timeline, and reproduction evidence. Separate facts, correlation, hypotheses, and unknowns. Use timeline, 5 Whys, causal chain, or fishbone dimensions for falsifiable hypotheses.
## Output and boundary
Output evidence summary, impact, hypotheses with confidence, validation experiments, temporary mitigation, durable fixes, and open items. State a block when material is missing; AI cannot confirm cause, approve a waiver, or close an incident.
