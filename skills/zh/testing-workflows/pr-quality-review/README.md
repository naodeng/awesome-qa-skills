# PR 质量审查工作流

提供 PR Diff、base/head SHA、验收标准及测试/CI 记录后调用 `pr-quality-review`。工作流组合现有代码审查、测试影响、测试有效性和质量门禁能力。

## 示例

> 审查 PR #42 的退款幂等改动，检查测试断言是否验证行为，按 P0/P1/P2 报告证据和阻断项；不要写回 PR。

## 最佳实践

提供完整 Diff 和稳定 SHA；运行证据附命令、退出码、环境、时间和来源；先说明团队严重度定义。

## FAQ

- 没有运行结果仍可做有限静态审查，状态写 `NOT_RUN` / `UNKNOWN`。
- 不假定专业 Skill 已安装；提供 Host 能力清单后再判断可用性。
- 外部评论、合并和审批默认不执行，需明确授权。
