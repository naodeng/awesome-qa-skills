# 验收标准评审
用于在测试设计前识别 AC 的可验证缺口。先读 `prompts/acceptance-criteria-review.md`；信息不足时区分事实、假设和待澄清项。输出可验证项、缺口、风险优先级和下一步，不编造规则或审批结论。
