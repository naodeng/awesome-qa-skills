# Agent 轨迹证据核对

把轨迹作为带来源的上下文，用来解释变更如何产生；它不能替代对代码和执行产物的核验。

逐项保留：

- run、step、tool call 和 evidence ID，以及它们提供的时间/顺序信息。
- 任务目标、输入引用、读取/修改的文件、工具参数和工具返回结果。
- 工具结果是否只是 Agent 自述、模拟输出、真实本地执行或 CI 平台产物；无法确定时标 `UNKNOWN`。
- 每个事件与最终 Patch、测试文件、锁文件、工作流配置的对应关系。
- 缺失的上下文、未包含在轨迹中的调用以及是否有独立人工复核。

轨迹声称 `PASS` 不等于测试或 CI 已执行；只有可定位的命令/平台结果、提交 SHA、时间、环境和退出状态才构成相应运行证据。缺少工具事件不证明 Agent 没有调用工具。
