# k6 结果解读指南

本指南说明如何解读由 `K6_SUMMARY_EXPORT` 生成的 k6 测试汇总结果。

## 1. 必需指标

- 请求总数、检查通过率与失败率
- 响应时间：平均值、中位数、p90、p95、p99 与最大值
- 每秒迭代数和请求数
- 错误率，以及按错误代码或错误类型归类的错误
- 虚拟用户数、阶段配置和实际执行时间

## 2. 默认通过/失败基线

- 错误率应低于 1%。
- p95 响应时间应满足测试计划中的阈值。
- 吞吐量应达到目标，且不出现持续下降。
- 不应有未解释的检查失败、脚本错误或基础设施错误。

当脚本明确配置压力、突发或耐久场景时，使用场景专属阈值。

## 3. 建议的报告结构

1. 测试目标、范围、环境和数据集
2. 负载模型、阶段设置和实际执行时间线
3. 关键指标与通过/失败判定
4. 错误分布、异常日志和受影响接口
5. 瓶颈假设、风险和后续行动

将结论与测试计划、监控数据和已知环境限制一起说明；可使用 `scripts/tools/` 中的汇总工具快速查看趋势。
