# Skill 弃用与归档指南

当能力被更清晰的 Skill 覆盖、职责重叠无法合理合并，或维护成本无法证明价值时，可提出 Deprecated。提案必须给出替代 Skill、保留边界、迁移说明、受影响文档和 Eval/安装影响。

Deprecated 不等于删除：保留目录和历史可追溯性，Matrix、Catalog、Map、README 与 Workflow 标注替代路径。仅在替代路径稳定、历史安装需求明确处理且文档保留后，才可进入 Archived。不得静默删除或以弃用掩盖未经验证的 Match 结论。
