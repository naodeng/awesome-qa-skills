# Skill Design Guide

Every New or Enhance delivery defines the quality problem, Scope, Non-goals, inputs, outputs, decision logic, evidence boundary, and Human Decision boundary. New Skills are independently installable and bilingual, with `SKILL.md`, main prompt, `agents/openai.yaml`, and success/insufficient-information/risk-boundary Evals.

Keep methodology, analysis, and tool adapters separate. Prefer Workflows for composition. Missing information produces a minimal executable plan and explicit questions; never invent requirements, execution facts, thresholds, or root causes.
