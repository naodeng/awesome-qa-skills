## Shared contract and evidence boundary

- `scripts/tests/v3_v4_skill_contracts.py` is the single test data source for the 42 card IDs, stable prefixes, Match conclusions, domain markers, and the new-package file contract.
- Each of the 41 `NEW` language packages must contain `SKILL.md`, a primary Prompt, OpenAI metadata, three Eval cases, trigger CSV, and local rules; the enhancement mode reuses the `prompt-testing` physical directory.
- Each Prompt first records `known`, `missing`, `conflicting`, `stale`, `out_of_scope`, and `assumptions`, then separates facts, evidence-backed inferences, candidate recommendations, and `Human` decisions.
- Static directories, names, trigger dry-runs, `skill-up validate`, unit tests, and quality gates prove structure and declarations only. They do not prove real-model behavior, executed tests, absence of vulnerabilities, coverage, quality scores, risk acceptance, business approval, or Release completion.
- Project status is an external execution record. `gh project item-list` proves current status only; without an event-history source, `transition_audit` remains `UNASSESSED` and acceptance cannot be upgraded to full business acceptance.
