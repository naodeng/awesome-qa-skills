# Candidate Skill 15-Step Execution Template

Copy this checklist for one candidate capability. Retain inputs, evidence, responsibility boundaries, and incomplete states at every step; complete Match before deciding Enhance, Merge, or New.

## Checklist

1. **Identify Quality Gap**: state the quality problem, user, and impact.
2. **Search Existing Skills**: inspect bilingual directories, Matrix, Catalog, Workflow, and similar/Plus packages.
3. **Capability Match**: compare Name, Purpose, Input, Output, Decision Logic, and Workflow Role.
4. **Decide**: choose `EXISTING`, `MATCH`, `ENHANCE`, `MERGE`, or `NEW` with evidence.
5. **Define Scope**: state ownership, inputs, outputs, and lifecycle stages.
6. **Define Non-goals**: state excluded domains, tools, approvals, and execution behavior.
7. **Design Input / Output**: define required information, incomplete input, result fields, and evidence links.
8. **Define Decision Logic**: separate facts, inferences, candidate recommendations, and Human Decision.
9. **Implement**: create an independent bilingual package only for an approved `NEW`; Enhance/Merge existing packages first.
10. **Eval**: add success, incomplete-information, and scope/risk-boundary cases; use `NOT_RUN` without an environment.
11. **Workflow Integration**: confirm composition, order, and outputs; arrows are not installation dependencies.
12. **Documentation**: synchronize README, Catalog, Map, Matrix, installers, and bilingual entry points.
13. **Release**: list version, quality gate, migration, rollback, and human release decision; use `NOT_RUN` without approval.
14. **Observe Usage**: collect actual invocation, false trigger, missing-input, and maintenance feedback; use `UNASSESSED` without data.
15. **Re-evaluate**: use new evidence to revisit Match, score, Eval, Workflow, and Deprecation state.

## Do not skip the boundary

Directory presence, trigger matches, passing static tests, or a Done Project card cannot replace semantic equivalence, real execution, model effectiveness, business acceptance, or release approval.
