# v1.4 Governance and Release Closeout Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 一次性完成 Project #4 中全部 v1.4 卡片的仓库交付、证据收口和 Project 状态同步，同时不提前启动 v1.5–v1.8。

**Architecture:** 用 JSON-compatible YAML 维护 v1.4 卡片与证据契约；Python 标准库生成双语 Phase 0 closeout 和 v1.0/v1.4 Release DoD 视图。现有 Registry、Matrix、Inventory、README、Catalog、Lifecycle、Deprecation、Quality Gate 与安装文档作为证据源，所有静态、结构、Eval 执行和发布审批状态分开记录。

**Tech Stack:** Python 3 standard library、JSON-compatible YAML、Markdown、`unittest`、现有仓库质量门禁、GitHub Project CLI。

**Spec:** `docs/governance/SKILL_GOVERNANCE_ROADMAP.md`、`docs/governance/SKILL_GOVERNANCE_V1.md`、`docs/SKILL_MATCHING_GUIDE.md`、`docs/SKILL_LIFECYCLE.md`、`docs/SKILL_DEPRECATION_GUIDE.md`、`docs/SKILL_QUALITY_GATE.md`、`docs/governance/DOCUMENTATION_POLICY.md`，以及 Project #4 的 v1.4 卡片。

## Global Constraints

- v1.4 只处理当前 Project #4 中 35 张目标版本为 `v1.4` 的卡片；v1.5、v1.6、v1.7、v1.8 不提前移动或实现。
- 不因治理卡片创建重复物理 Skill；`MATCH`、`MERGE`、`ENHANCE`、`EXISTING` 结论不授权创建、删除或重命名目录。
- `NOT_SCORED`、`NOT_RUN`、`UNASSESSED`、`BLOCKED` 和 `N/A` 必须保留；静态检查不等于运行效果、模型 Eval、业务验收或发布批准。
- 所有当前有效项目级治理文档保持中文/英文镜像；生成视图只修改生成器和事实源，不手工编辑生成结果。
- Project 外部变更只移动 v1.4 卡片；不创建仓库 Issue，不提交、不推送、不发布 Release。
- 保留当前工作区中前序 v1.4 卡片的所有改动，不覆盖或回退无关文件。
