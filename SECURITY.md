# Security Policy

## Supported Versions

Only the latest state on the main branch is supported for security fixes. Other branches and tags do not have a separate support window.

## Reporting a Vulnerability

GitHub private vulnerability reporting is not enabled for this repository. Do not publish vulnerability details, exploit steps, or sensitive evidence in a public issue or pull request.

To report a concern, open a public issue containing only a request for a private reporting channel. Do not include technical details. Wait for maintainers to provide a private channel before sharing the report. There is no guaranteed response time.

## 安全政策

### 支持的版本

仅维护 main 分支最新状态的安全修复；其他分支和标签没有单独的支持周期。

### 漏洞报告

当前仓库未启用 GitHub 私密漏洞报告。不要在公开 Issue 或 PR 中发布漏洞细节、利用步骤或敏感证据。

如需报告，请先创建一条不含技术细节、仅请求私密报告渠道的公开 Issue。收到维护者提供的私密渠道后，再发送报告内容。项目不承诺固定回复时限。
